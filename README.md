Pistons Speed — Sitio web

Sitio web para Pistons Speed, taller mecánico especializado en motocicletas ubicado en Concepción, Chile. Enfocado en suspensión, mantención general, vulcanización y venta de neumáticos.

🔗 Sitio en vivo: https://joaquin-inzunza.github.io/pistons-speed/

Sobre el proyecto

Sitio de una sola página, diseñado a medida para un cliente real, con foco en conversión directa a WhatsApp y presencia en Google (datos estructurados para negocios locales).

Características
Diseño responsive (menú colapsable en mobile)
Identidad visual a medida basada en el logo real del cliente
Botones de contacto directo a WhatsApp e Instagram
Mapa de ubicación embebido (Google Maps)
Datos estructurados (Schema.org / JSON-LD) para mejorar indexación en Google
Stack
HTML5 semántico
CSS puro (sin frameworks) — variables CSS, Grid y Flexbox
JavaScript vanilla (menú móvil)
Hosting: GitHub Pages
